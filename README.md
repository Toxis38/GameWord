# GameWord — «Тайны слов» / Угадай слово

Веб-игра в жанре hangman (угадай слово) с регистрацией, монетами, магазином тем (снеговик / дом / робот), профилем, рейтингом и админ-панелью.

## Исправления в этой версии
- Труба у дома стоит нормально на крыше (не выше крыши)
- После покупки/выбора темы статус в магазине обновляется сразу (без перезагрузки страницы)
- В профиле время показывается в **секундах**, а не в минутах

## Запуск

1. Установите [Node.js](https://nodejs.org/)
2. Скопируйте `.env.example` → `.env` и укажите свои SMTP-данные (для писем подтверждения)
3. В папке проекта:
   ```bash
   npm install
   npm start
   ```
4. Откройте http://localhost:3000

Или на Windows просто запустите `start.bat`.

## Стек
- Node.js + Express
- SQLite
- Vanilla JS + CSS
